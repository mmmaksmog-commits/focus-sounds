# 🎧 Звуки фокуса

**Генеративный эмбиент для работы и сна.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/focus-sounds/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 8 звуков: дождь, костёр, море, ветер, кафе, лес, гроза, белый шум
- Все звуки синтезируются Web Audio — без аудиофайлов
- Пресеты, громкость каждого звука, визуализатор
- Таймер сна с плавным затуханием

## Стек

Web Audio API. Один файл `index.html`, без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/focus-sounds.git
cd focus-sounds
python3 -m http.server 8000
```
